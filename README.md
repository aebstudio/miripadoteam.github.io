# GitHub Pages 배포본

이 폴더의 **내용 전체**를 GitHub 저장소 루트에 업로드하세요.

## 중요
- `index.html`과 `assets` 폴더의 상대 위치를 바꾸지 마세요.
- 특히 실습 이미지는 `assets/practice/breez-320.webp`, `breez-640.webp`, `breez-960.webp`를 직접 사용합니다.
- GitHub Pages는 `Settings → Pages → Deploy from a branch → main / (root)`로 설정하면 됩니다.
- 이전 배포본을 교체할 때는 기존 파일을 삭제하거나 동일 파일명으로 덮어쓴 뒤 브라우저 강력 새로고침을 권장합니다.
