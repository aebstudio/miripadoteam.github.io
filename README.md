# 5주차 상세페이지 · GitHub Pages 배포본

이 폴더의 파일을 GitHub 저장소 루트에 그대로 업로드하세요.

- 시작 파일: `index.html`
- 정적 리소스: `assets/`
- 스타일: `*.css`
- 스크립트: `*.js`
- `.nojekyll`: GitHub Pages에서 Jekyll 처리를 건너뜁니다.

## GitHub Pages 설정
1. 저장소에 이 압축파일의 내용을 업로드합니다.
2. **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`로 설정합니다.

대용량 단일 HTML의 Base64 리소스를 파일로 분리하고, PNG 이미지를 WebP로 최적화한 경량 배포본입니다.
